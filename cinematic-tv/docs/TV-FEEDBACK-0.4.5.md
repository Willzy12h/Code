# 0.4.5 — approved visual and remote refinement

The update preserves the cinematic Home, large preview, compact Recently used, working weather and Settings thumbnail. The Home heading is visually removed; accessible Home naming remains. Native picture bounds are derived from the visible frame with six CSS pixels of inset at 1080p, scaled with viewport height, then converted to percentage coordinates. The native controller contains the detected aspect ratio in viewport space. The preview is a labelled remote target: Left → Recent, Down → Favourites, Up → Settings; focusing never switches/restarts video. OK uses the existing explicit fullscreen-input flow. A one-time preference migration selects PC and uses the confirmed HDMI 1 only if no PC port was saved; explicit ports remain intact. Subsequent explicit focus choices remain saved.

A single 140 ms favourite/app selection frame follows remote navigation without delaying key handling. Home does not translate during entrance because a native plane cannot follow an HTML transform. Other menu transitions and reduced-motion support remain. Wallpaper loads and decodes before a 500 ms crossfade, keeps the last good picture on errors and rejects stale decodes after newer choices. Automatic dimming is independent of image source and can be disabled: 30% day, 40% at sunrise/sunset, 50% night, interpolated through the surrounding half-hour windows. It uses the saved weather location's cached IANA timezone and Unix sunrise/sunset times, with the agreed local-time fallback if unavailable. Existing weather fetches carry the additional solar fields; no new network hosts or privileges were added. Hidden weather can still supply solar data while dimming is enabled.

Launch feedback is diagnostics-only: request, acceptance and foreground-handoff elapsed milliseconds are recorded without adding Opening/Waiting text, spinner or banner. Existing errors remain visible. Diagnostics export remains redacted and does not contain the user's watch history or source URLs.

The existing confirmed artwork stays. Pinned Simple Icons geometry adds Channel 4, Philips Hue/Hue Sync and SmartThings; Spotify is green. Disney+, BBC iPlayer, BBC Sounds and Samsung Health use complete, readable brand-name treatments rather than unverified native images or invented logos. Other native artwork remains uncropped. Exact sources, hashes and licence/disclaimer notes are in assets/brands. The installed icon is an authored cinema-screen/C monogram, with editable SVG and 512px PNG.

Settings have an internally padded dark backing, safe scroll margins and fully revealed focused rows. Home profiles explicitly explain optional favourites/appearance presets and show No presets saved / Save current Home. Applying presets excludes weather, history and experimental preview. Undo after hiding or removing a Home pin is a ten-second, single delta; replacement, expiry, focus and non-destructive restoration are covered. Inputs, Previous and Edit Home behaviour is retained. A separate remote-first Edit Home redesign is future work, not implemented here.

The full verification suite covers 68 Node tests, existing browser/HDMI checks, 18 readiness scenarios, eight existing feedback cases, 39 settings, seven artwork/management cases and eight refinement scenarios. Updated old assertions correspond only to explicitly changed focus/heading/feedback/coordinate/timing behaviour; native ownership, source-switch safety and CSP tests remain. Browser capture is not native TV video acceptance. Physical frame alignment, remote feel, artwork and startup behaviour must be observed on the S95H after installation. Current signing/install/CI fingerprints belong in the local delivery report.

Default/return investigation is in STARTUP-RETURN-INVESTIGATION.md. User-reported baseline: Smart Hub Home is Off, Autorun Last App is absent. No native setting, Home mapping, watcher or service was changed. Community approaches were inspected only and require a separate approval and device-specific recovery proposal. Do not imply automatic app return or permanent default Home has been implemented.
